# Go agent rules
Read ../AGENTS.md, ../docs/development/testing-strategy.md and ../api/openapi.yaml. This directory holds one shared MVP Go agent for Edge (branch wire value) and Hub. All management connections initiate outbound HTTPS; verify server TLS and use issued device certificates. Never print enrollment tokens/private keys, run arbitrary shell commands, or apply networking in the management-channel MVP. Config acknowledgements are received/rejected, not applied. Run go test ./..., go test -race ./..., go vet ./..., go build ./cmd/fabric-agent after changes. Update change logs through the root locked writer. Keep state/key files private and uncommitted. Actual WG/FRR/nft apply and rollback belong to later approved milestones.
