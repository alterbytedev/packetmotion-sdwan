# Go agent rules
Read ../AGENTS.md, ../docs/development/testing-strategy.md and ../api/openapi.yaml. This directory holds one shared Go 1.27.2 MVP agent for Edge (branch wire value) and Hub. All management connections initiate outbound HTTPS; verify server TLS and use issued device certificates. Never print enrollment tokens/private keys, run arbitrary shell commands, or apply networking in the management-channel MVP. The agent stages checksummed typed desired revisions and acknowledges received/rejected; it does not claim applied state. Heartbeat/interface telemetry and certificate renewal are implemented. Run `go test ./...`, `go test -race ./...`, `go vet ./...`, and `go build ./cmd/fabric-agent` after relevant changes. `npm run test:agent` in the controller provides an isolated Go/NGINX/Next integration smoke when Docker, OpenSSL and Go are available. Update change logs through the root locked writer. Keep state/key files private and uncommitted. Actual WG/FRR/nft generation, apply, rollback and forwarding verification belong to later milestones.
